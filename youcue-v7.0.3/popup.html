Additional information

Custom cues

Each YouTube video keeps its own cue locations. Once you set a number cue, that saved cue replaces YouTube's normal percentage jump for that number.

YouTube auto cues

When this is on, any number you have not set behaves like normal YouTube: 1 goes to 10%, 2 to 20%, and so on; 0 goes to the beginning. When it is off, unset numbers do nothing.

One shot mode

One shot behavior applies when you trigger a cue from a paused video. The cue starts playing while you hold it, and playback pauses again when the last held cue is released. Hold R if you want note repeat. With One shot mode off, holding a cue itself starts repeat.

Moving cues

Z moves backward and X moves forward, but only when paired with R or E. Use R + cue + Z/X to hear the point repeat while you move it, or E + Z/X to adjust the last number cue. Movement stays completely manual.

Looping

Press I where the loop should start. Press Option + I where it should end; the loop starts immediately and returns to IN. O exits or restarts the saved loop. Number cues still work independently.

Repeat length

BPM and the selected division determine repeat speed. [ makes the repeat shorter and ] makes it longer. The shortest repeat is 1/32.

Fade out

Fade duration is measured in milliseconds. A small value keeps repeats sharp; a larger value softens the transition more. The slider sets the fade time used for note-repeat smoothing.

Tap tempo

Tap the apostrophe key several times to estimate BPM. It works directly on YouTube even when the popup is closed.

Block YouTube shortcuts

This blocks YouTube's normal playback and viewing keyboard commands, such as Space, J/K/L, arrows, F, M, C, and similar shortcuts. YouCue's own cue, loop, repeat, and edit keys keep working. Typing in search boxes or comments is not blocked.

Saved data

Cue and loop locations save automatically for every video you edit. A Storage bookmark is separate: it gives you a named video list you can reopen later and protects that video's autosaved data from cleanup.
